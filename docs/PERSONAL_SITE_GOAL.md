> 状态：方向基线 v2  
> 更新日期：2026-07-28  
> 用途：约束下一版的产品、内容、视觉与工程决策  
> 本文记录已经拍板的当前真理。历史方案与本文冲突时，以本文为准。

## 一句话定义

这是一个以视觉体验为第一价值、用于自我介绍、交友和作品展示的个人网站。

它可以包含博客，但不是博客优先的内容站，也不要求持续写作。它首先要像一件属于 Rain_dust 的个人作品：第一眼好看，继续看觉得这个人有意思，最后通过真实项目发现这个人还挺厉害。

## 核心目标

按优先级排序：

1. **好好看**
2. **这个人有意思**
3. **这个人还挺厉害**

主要使用场景：

- 自己看着舒服，愿意反复打开；
- 认识新朋友时，直接发送网站链接完成自我介绍；
- 参加黑客松、面试或合作沟通时，展示真实作品与能力；
- 偶尔发布文章、随笔或笔记，但不承担固定更新压力。

“厉害”必须来自作品、细节和完成度，而不是自我吹嘘或设定台词。

## 产品母体：四个独立空间

网站不是一张向下滚动的长宣传页，而是四个彼此独立、通过共同导航连接的空间：

| 入口 | 路由 | 作用 |
| --- | --- | --- |
| HOME / front page | `/` | 动态视觉封面与身份入口 |
| BLOG / notes | `/blog` | 可选的文章、随笔与笔记空间 |
| WORKS / projects | `/works` | 塔罗牌式作品展示空间 |
| ME / profile | `/me` | 完整人物档案与个人 README |

约束：

- `GAME` 不存在；
- 不通过向下滚动从 HOME 进入 BLOG、WORKS 或 ME；
- 页面内容较多时，可以在当前空间内部滚动，但滚到底不会进入另一个大区；
- 每个空间拥有自己的 URL，浏览器前进、后退与直接分享必须正常工作；
- HOME、WORKS 与 ME 应各自拥有可独立截图和记忆的视觉母体。

## 视觉总纲

整站的视觉命题是：

**月白表面，暗影内核。**

它不是纯暗黑网站，也不是甜系二次元主页，更不是紫蓝霓虹、毛玻璃和终端装饰组成的技术模板。它应像一个外表安静、内部藏着私人世界的人。

### 核心色

- 月白：`#F1EFE9`
- 炭黑：`#151613`
- 暗红：`#8C2935`
- 旧金：`#B49A68`

使用边界：

- 暗红只用于红瞳、选中状态和少量关键文字；
- 旧金主要属于 WORKS 的塔罗纹饰；
- 避免大面积高饱和紫色、蓝色与霓虹渐变；
- 页面可以拥有不同明暗气氛，但必须仍属于同一套色彩系统。

### 字体方向

- 导航、身份与 UI：干净的中文黑体；
- 自我介绍、小说与番剧短评：中文宋体；
- `README.md`、日期与少量元信息：等宽字体；
- 不使用动漫字体，不用巨大衬线标题冒充高级感。

### 动效原则

全站只保留有明确作用的动态：

- HOME 的雨、浮尘与角色呼吸感；
- 顶部导航的出现与收起；
- 房间切换时的暗幕换景；
- WORKS 的塔罗牌抬起、移动与翻面；
- ME 的书页翻动。

不让所有文字漂浮、所有按钮发光或所有页面共享同一种入场动画。关闭动画后，静态画面仍然必须成立。

白发红瞳少女是网站的固定审美角色与陪伴性形象，不是作者本人。

形象要求：

- 身材修长，视觉设定约 165–170cm；
- 白发、红瞳；
- 浅色短裙或轻盈日常服装；
- 自然光腿、赤足；
- 不幼态、不萝莉化、不御姐化；
- 不刻意性化，不采用真人肖像感；
- 形象稳定，不在不同页面随意更换设定。

角色分工：

- 男主头像：**这是我**
- HOME 男主片段：**这是与我高度共鸣的人格气质**
- 白发少女：**这是我的审美与私人世界**
- 塔罗牌项目：**这是我做出来的东西**

### 《想要成为影之实力者》男主片段

这一片段承载“像另一个我”的人格共鸣，并作为 HOME 的主要动态视觉。

- 当前 15 秒素材用于首版原型，后续尽量替换为 1080p 或更高质量的原始片源；
- HOME 不直接播放完整蒙太奇，而是重排成约 8–9 秒的短循环；
- 姓名只在开场安静侧脸镜头出现，进入动作镜头后淡出；
- 推荐镜头顺序：安静侧脸 → 普通学生状态 → 兜帽与红眼 → 力量显露 → 压暗回到开场；
- 默认静音自动播放，不让声音承担信息；
- 公开部署前需要确认商业动画素材的授权与使用边界。

## HOME：暗影人格的动态封面

HOME 是完整的单屏封面，不是内容聚合页。

### 构图

- 页面固定为 `100dvh`，默认不出现纵向滚动条；
- 男主片段全屏覆盖，暗部保持层次，不额外叠加霓虹特效；
- 首个安静侧脸镜头是身份建立段；
- 身份文字靠近侧脸镜头的留白区，只显示：

  ```text
  寻辰沐雨
  Rain_dust
  Vibe Coder
  ```

- 镜头进入学生状态、兜帽红眼与力量显露后，身份文字淡出，让视频接管注意力；
- 顶部中央只保留导航拉条；
- 不放自我介绍、作品入口、联系方式、近期文章或“向下滚动”提示。

### 动态

- 当前原型循环约 8–9 秒；
- 开场安静侧脸约 2 秒，用于显示身份；
- 中段用普通状态与暗影状态形成反差；
- 高强度镜头只在循环后半段短暂出现；
- 结尾压暗后回到侧脸镜头，避免生硬回跳；
- 不额外添加鼠标粒子、光污染或与原片争夺注意力的装饰动画。

页面应先立即显示从开场侧脸镜头提取的静态封面，再在视频准备完成后平滑进入动态版本，避免黑屏等待。

首版移动端允许使用当前横版素材的重点裁切与静态兜底，但必须保证侧脸、红眼和身份文字不会同时被裁掉。后续寻找或制作竖版素材时，再替换为独立构图。

HOME 的招牌截图只包含：**男主安静侧脸、寻辰沐雨、Rain_dust、Vibe Coder、顶部拉条。**

白发红瞳少女不再阻塞 HOME 首版。她保留在 WORKS 的发牌者局部与 ME 的 XP 页面中。

## 顶部导航：上悬门廊

导航是四个空间唯一共享的主要交互。

### 结构

桌面端使用居中的横向圆角导航：

- HOME / front page
- BLOG / notes
- WORKS / projects
- ME / profile

视觉使用稳定的象牙白实体感，不使用强毛玻璃、彩虹渐变或厚重霓虹。

### 展开与收起

- 收起时，页面顶部中央只露出一枚小拉条；
- 拉条中间保留一道暗红细线；
- 首次访问时轻轻下探一次，此后不重复跳动；
- 页面顶部约 40px 为鼠标感应区域；
- 光标进入后，导航落到距离顶部约 20px 的位置；
- 光标离开导航后延迟约 500ms 收起；
- 当前页面用浅色凹陷底面和细下划线表示；
- 点击当前入口只收起导航，不重新加载当前页面。

### 暗幕换景

选择另一个空间时：

1. 选中入口的细下划线亮起；
2. 炭黑色暗幕从导航下沿落下，覆盖当前场景；
3. 新页面在暗幕后完成切换；
4. 暗幕向上收回；
5. 导航同时隐藏，露出新的空间。

完整过程约 500ms。它不是加载动画，不得用假进度或强制等待拖延时间。

### 移动端与可访问性

- 移动端点击顶部拉条展开全宽横向导航；
- 移动端只显示图标和 HOME、BLOG、WORKS、ME，不显示英文副标题；
- 点击页面空白或向上滑动可收起；
- 键盘 `Tab` 能展开并聚焦导航，`Esc` 收起；
- 支持清晰的焦点状态；
- `prefers-reduced-motion` 下使用短淡入淡出替代暗幕和复杂位移。

## WORKS：月光下的牌桌

WORKS 是一个独立的全屏项目空间，不是项目卡片墙。

### 空间

- 深炭黑牌桌或桌面；
- 窗外冷光照入；
- 五张项目塔罗牌以轻微弧形铺开；
- 少女只在画面边缘露出局部身影或手臂，像发牌者；
- 视觉中心始终是项目牌。

### 首批项目

1. [Earth Online](https://github.com/Rain-dust/earth-online)
2. [浮生录](https://github.com/Rain-dust/fushenglu)
3. [MindCache](https://github.com/Rain-dust/MindCache)
4. [Campus Reimburse Kit](https://github.com/Rain-dust/campus-reimburse-kit)
5. [知微](https://github.com/Rain-dust/Zhi-Wei)

后续可以继续增加项目，但首屏不能退化成无限扩张的规则网格。

### 塔罗牌正面

- 罗马数字；
- 真实项目名称；
- 真实项目截图或代表性图像；
- 每个项目独有的象征图案；
- 克制的旧金色塔罗纹饰。

不虚构“大阿卡纳”名称，不用神秘设定替代真实项目信息。

### 交互

- 悬停：牌轻微抬起并朝光源倾斜；
- 单击：牌移动到屏幕中央、放大并翻面；
- 翻面：展示两三句介绍、主要技术与 `VISIT PROJECT ↗`；
- 点击空白处：牌回到原位；
- 双击牌面：直接打开对应项目链接；
- 同一时间只展开一张牌；
- 选中牌时，桌面光影向它聚拢，其他牌适度压暗。

双击不是唯一的访问方式。移动端、键盘与辅助技术用户必须能通过明确链接访问项目。

桌面端展示完整牌阵；移动端显示一张主牌和左右邻牌的边缘，通过横向滑动换牌。

底部只保留轻量提示：

`CLICK TO REVEAL · DOUBLE CLICK TO VISIT`

## ME：摊开的私人设定集

ME 不是简历页、资料卡墙或需要寻找隐藏物品的房间，而是一本现代、清晰、可以翻阅的个人设定集。

整体材质：

- 米白纸张；
- 深灰文字；
- 少量暗红批注；
- 安静桌面；
- 不做破旧魔法书，不堆胶带、贴纸和假终端窗口。

### 默认跨页：`README.md`

左页：

- 圆形网络头像；
- 寻辰沐雨；
- Rain_dust；
- Vibe Coder；
- INTP / 白羊座。

右页：

- 简短自我介绍；
- GitHub；
- Email。

`README.md` 使用真实 Markdown 内容源维护，而不是只把普通简介面板命名为 README。

### 书页标签

- `README.md`
- `NOW`
- `FAVORITES`
- `XP`
- `STACK`

点击标签翻到相应跨页，并更新 URL 锚点，例如 `/me#xp`。

### 内容

`NOW`

- 最近在做什么；
- 最近在折腾什么；
- 最近沉迷什么；
- 只显示两三项与真实更新时间。

`FAVORITES`

- 左页展示喜欢的番剧；
- 右页展示喜欢的小说或网文；
- 每项使用封面、标题和一句真实短评；
- 不复制剧情简介，不伪装成权威排行榜。

`XP`

- 允许比其他页更自由、更私人；
- 直接呈现真实审美偏好；
- 白发红瞳少女在这里成为主要画面；
- 具体词条由用户提供，不由系统臆测。

`STACK`

- 展示真实常用和正在学习的技术；
- 可按“经常使用 / 正在折腾”区分；
- 不使用技能进度条、百分比或虚构熟练度。

翻页是 ME 的唯一主要动效，约 350ms，并带有克制的纸张阴影。手机端改成单页档案册：顶部保留圆形头像，标签横向排列，正文在当前纸页内部滚动。

## BLOG：保留但不施加写作压力

BLOG 暂不承担首版核心价值，也不要求为项目配套写文章。

当前边界：

- 允许零篇、几篇或很多篇文章；
- 作品可以直接跳转项目，不依赖作品文章；
- 首页不展示近期文章；
- 首版不要求标签云、搜索、RSS、归档、推荐阅读或复杂分类；
- 后续文章可以使用 Markdown 或 MDX 增加；
- 博客列表与阅读页的具体视觉母体暂缓讨论；
- 即使没有文章，BLOG 页面也不能看起来像构建失败。

BLOG 的存在是为未来表达保留空间，不是为了制造持续更新义务。

## Astro 工程目标

当前项目已经使用 Astro 7，继续沿用 Astro 静态站架构，但产品不再以“Astro 博客”为定义。

工程原则：

- 四个空间使用独立路由；
- 全局导航与暗幕换景由共享外壳负责；
- HOME、WORKS、ME 分别拥有独立组件与样式边界；
- 作品数据、ME 内容与博客文章从页面结构中分离；
- 新增作品不复制整段页面代码；
- `README.md` 由真实 Markdown 文件驱动；
- NOW、FAVORITES、XP、STACK 使用清晰的数据源；
- BLOG 在需要时使用 Content Collections；
- 默认静态输出，只为导航、牌面与翻页等局部交互加载客户端脚本；
- 视觉媒体提供封面图、加载失败回退与移动端专用资源；
- 页面切换前预取站内轻量路由，避免暗幕后出现空白；
- 不把 Canvas、WebGL 或全局滚动进度作为首版成立的前置条件；
- 支持 `prefers-reduced-motion`、键盘操作与基本语义化结构。

首版技术完成不等于“能跑”。它还必须确保媒体加载失败、动画关闭、触摸操作和键盘操作时，网站仍能被理解和使用。

## 首版实施顺序

1. 建立全局设计变量、四个路由与上悬导航；
2. 打通暗幕换景、键盘与移动端导航；
3. 完成 HOME 视频剪辑、静态封面与身份文字时序；
4. 完成 WORKS 牌桌、真实项目数据与项目跳转；
5. 完成 ME 设定集、圆形头像和真实内容源；
6. 为 BLOG 提供不尴尬的基础入口，详细设计延后；
7. 完成移动端专项构图、性能与减少动态效果验证。

## 首版成功标准

- 访问者第一眼认为网站好看，而不是先看到功能列表；
- 访客能在短时间内看见“寻辰沐雨 / Rain_dust / Vibe Coder”；
- 顶部导航可以被发现，但平时不破坏沉浸感；
- 四个空间之间不依靠纵向滚动串联；
- HOME 的开场静态截图本身成立，视频加载或播放失败时不坍塌；
- WORKS 明确展示真实项目，单击、双击、触摸与键盘路径都可用；
- ME 能快速读到身份、联系方式、近况、喜好、XP 与技术栈；
- 手机端不是桌面布局的缩小版；
- 关闭动画后仍能导航、阅读和访问项目；
- 新增项目或修改个人内容不需要重写核心页面；
- 网站最终形成明确印象：**好好看 → 这个人有意思 → 这个人还挺厉害。**

## 已关闭的方向

以下方向不再作为当前方案的一部分：

- 以博客和长期写作为网站核心；
- 首页展示近期文章和精选作品；
- HOME、人格与作品通过向下滚动串成连续三幕；
- 为每个作品强制撰写文章或完整案例研究；
- 连续的不对称编辑式作品长画面；
- 规则重复的项目卡片墙；
- 永久悬浮且始终占据画面的导航栏；
- `GAME` 区域；
- 使用白发少女作为作者头像；
- 公开学校、专业、城市、年龄或真实姓名；
